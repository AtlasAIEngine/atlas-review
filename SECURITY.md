# Security policy

Security fixes target the latest stable release. Upgrade before reporting a problem where possible.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Loomtide/atlas-review/security/advisories/new). Include the affected version, reproduction steps, impact, and a minimal example without live secrets or private repository content. Do not disclose vulnerabilities, credentials, or private code in public issues.

Reviews use the AI provider you configure. Imported repositories, provider CLIs, and MCP actions can access local developer resources. Use trusted repositories and inspect actions before publishing or applying changes.
